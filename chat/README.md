# Simple Chat Using JsHttpRequest

**Author**: [Misha v.3](https://www.parser.ru/forum/members/?id=17), May 16, 2006
**Version**: 1.2
**Tags**: JS, Chat

I'd never written a chat before, so I decided to give it a try using the previously-written `JsHttpRequest.p`. You can see what came out of it [in action](https://www.parser.ru/_/chat/) or download the source. Oh, I forgot to mention: to see it in action you need to be registered and logged in.

Keep in mind that the chat is tailored to work with my authentication class, and the example uses (but doesn't include in the archive) what's covered in the other examples (about the [SQL classes](https://www.parser.ru/en/examples/sql/), the authentication class, and `JsHttpRequest.p`).

Looking at the scripts that create the database tables, you'll probably notice that the tables are set up to serve multiple chats at once, but nothing like that is actually implemented in the code, since I didn't need it myself. Go for it :)

[Original documentation on parser.ru](https://www.parser.ru/en/lib/chat/)
